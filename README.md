# 🌱 女兒英語情景學習卡 · Daily English Cards

為 4 歲女兒設計嘅互動英語學習平台，方便一家三口一齊學。

## 特色
- 🎨 卡通可愛風情景插畫
- 📝 每個場景重點生字（配圖 + 音標 + 中文）
- 💬 親子情景對話（媽媽 ↔ 女兒）
- 🀄 中文對照
- 🔊 真人感英語發音（Google Cloud TTS）
- 🎯 親子互動小任務
- 📱 可揭頁互動網頁

## 10 個日常場景
刷牙、食早餐、著衫、返學、玩玩具、沖涼、食生果、去公園、睇書、瞓覺

## 設定
1. Settings → Secrets and variables → Actions 加 Secret：`GOOGLE_TTS_API_KEY`
2. Actions 執行「Generate Audio」workflow
3. Settings → Pages 開啟 GitHub Pages

## 語音
- 👩 媽媽：en-US-Neural2-F（溫柔女聲）
- 👧 女兒：en-US-Neural2-C（活潑童聲）
- 語速：0.85x
